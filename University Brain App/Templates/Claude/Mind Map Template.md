## How to organise Mind Map notes

- **How the app shows this note:** the page's **Details** card shows type, course, date and status, and **Relates to** lists the notes in `related` plus the notes that link back to it. Link the Items notes this one draws on through `related`.
- Name it `{Course Name} - Mind Map - {Topic}`. Link `Course:: [[Course Name]]` (capital C on this type) and set `date` to when it was made or is due.
- `type` is one of: `Mind Map`.
- One note per map, filed in `Apps/Mind Maps`.
- Keep each node to a few words; put the explanation in the linked Items note.
- Set `type` to `Mind Map`.
- Keep `status` current (`Not started` → `In Progress` → `Done`).
