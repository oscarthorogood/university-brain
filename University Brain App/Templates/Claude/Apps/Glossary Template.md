## How to organise Glossary notes

- **How the app shows this note:** the page's **Details** card shows type, course, date and status, and **Relates to** lists the notes in `related` plus the notes that link back to it. Link the Items notes this one draws on through `related`.
- Name it `{Course Name} - Glossary - {Topic}`. Link `Course:: [[Course Name]]` (capital C on this type) and set `date` to when it was made or is due.
- `type` is one of: `Glossary`.
- One note per course or topic, filed in `Apps/Glossary`.
- Define in one sentence and cite the source; add the term once.
- Set `type` to `Glossary`.
- Keep `status` current (`Not started` → `In Progress` → `Done`).
