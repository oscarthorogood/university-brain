## Resources folder

Finished reference files only (slides, documents, data, images, media), never notes or drafts: `Files/Resources/{Course}/{Type}/`, or `Files/Resources/General/{Type}/` for anything not tied to a course. Types: Slides, Documents, Spreadsheets, Data, Images, Media, Code, Archives. File names are lowercase and hyphenated. Every file is linked from a note's `resources`; a new version replaces the old file.
