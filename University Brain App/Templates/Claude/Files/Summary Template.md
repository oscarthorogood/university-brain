## How to organise Summary notes

- **How the app shows this note:** the page's **Details** card shows type, course, date and status, and **Relates to** lists the notes in `related` plus the notes that link back to it. Link the Items notes this one draws on through `related`.
- Name it `{Course Name} - Summary - {Topic}`. Link `Course:: [[Course Name]]` (capital C on this type) and set `date` to when it was made or is due.
- `type` is one of: `Summary`, `Handout`, `Code`.
- One note per topic sheet, filed in `Apps/Summaries`.
- Link the Items notes it condenses through `related` instead of copying them.
- Set `type` to `Summary`, `Handout` (a lecturer's sheet) or `Code` (a code cheat sheet).
- Keep `status` current (`Not started` → `In Progress` → `Done`).
