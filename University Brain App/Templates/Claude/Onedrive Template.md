## How to organise OneDrive-linked files

The `onedrive` field (used on Essay, Lecture, Project, and Reading notes) points out to files that live on OneDrive rather than inside the vault — typically active working documents, submissions, and anything too large or too frequently edited to store as a vault attachment.

- Mirror the vault's course structure on OneDrive: `Files/OneDrive/{Course Name}/{note type}/`, e.g. `Files/OneDrive/Introduction to AI/Essays/`, `Files/OneDrive/Introduction to AI/Projects/`. Every course-related file belongs under its course folder — nothing tied to a course should sit loose at the top level of the OneDrive vault area.
- Use OneDrive for anything still in progress — draft essays, in-progress project files, working spreadsheets. Once a piece of work is finished and finalised, move a copy of the finished output into the matching `Resources` folder in the vault and keep the `onedrive` link pointing at the live/original version.
- Link to the specific file, not the containing folder, from the `onedrive` field — this keeps the linked-mentions view precise and avoids ambiguity about which file the note refers to.
- Keep OneDrive folder and file names consistent with the naming conventions used for the corresponding vault notes, so the two systems stay easy to cross-reference.
- Don't duplicate content between OneDrive and the vault note — the vault note should summarise and link, not copy-paste the working document's contents.

## Pulling detail from files into notes

Files hold the detail; notes hold what matters from them. Whenever a file is linked from a note, read it and extract into that note:

- **Slides** → lecture structure, learning objectives, definitions, frameworks, formulas, examples, references cited, announcements.
- **Briefs and rubrics** → question (verbatim), weighting, word limit, deadline, submission rules, marking criteria.
- **Exemplars** → structure used, what earned marks, what to avoid.
- **Tutorial sheets and solutions** → questions (verbatim) and model answers.
- **Past papers, mark schemes, examiner reports** → questions, marks, examiner comments.
- **Readings (PDFs)** → verified citation, structure, argument, method, findings, definitions, quotes — each with a page number.
- **Spreadsheets and data** → what the file contains (sheets, variables, period) and which question it serves.

Rules: cite the location (`slide 12`, `p. 4`, `Sheet "Data"`); summarise rather than paste; copy only questions, briefs and quotes verbatim; leave a field blank rather than guess; match a file to its course by content, not filename.
