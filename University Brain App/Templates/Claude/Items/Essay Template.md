## How to organise Essay notes

- **How the app shows links:** the note page's **Related** card lists every Revision, Research, Zotero, Resources or OneDrive item this note links to (through `resources`, `onedrive`, or any `[[link]]` in the text) or that links back to it. **Links to** lists the other Items notes it links to (through `related`, `readings` or any `[[link]]`). Properties (course, date, status, tags) are edited on the page. Link things once, with a wikilink; don't repeat them by hand.
- One note per essay or individual written assignment, filed in the top-level `Essays` folder — never inside the course folder itself.
- Link the note to its course with `course:: [[Course Name]]`; this is what groups it under the right course in Bases views, not the folder it sits in.
- Set `due` as soon as the essay is set so it shows up in date-based views and TaskNotes, copy the deadline to the course note's Key dates, and keep `status` current (`Not started` → `In Progress` → `Done`).
- Use `resources` for the brief, rubric and exemplars, `readings` for the Reading notes actually used, and `references` for the citation list or bibliography note.
- If the finished essay file itself lives on OneDrive (e.g. the submitted .docx/.pdf), link it via the `onedrive` field rather than duplicating the content into this note.
- Keep `summary` to one line: assessment, weighting and question or thesis, so essays are scannable from a course's linked-mentions list.

**Pulling detail from attachments**
- Read the brief and rubric in full before writing anything else. They fill **Brief at a glance**, **The question** (verbatim) and **Marking criteria**.
- Exemplars fill **Exemplars**. Lecture slides that describe the assessment count as attachments too. Check the course's L01 note.
- When a document doesn't name its course, match it by content (deadlines, question style, tutorial group), never by filename.
- Cite the page for every extracted detail, and leave a row blank rather than guess.
