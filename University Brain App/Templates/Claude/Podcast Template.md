## How to organise Podcast notes

- **How the app shows this note:** the page's **Details** card shows type, course, date and status, and **Relates to** lists the notes in `related` plus the notes that link back to it. Link the Items notes this one draws on through `related`.
- Name it `{Course Name} - Podcast - {Topic}`. Link `Course:: [[Course Name]]` (capital C on this type) and set `date` to when it was made or is due.
- `type` is one of: `Podcast`.
- One note per episode, filed in `Apps/Podcast`; keep the audio file beside it.
- Link the audio on an `Audio:` line so the app can play it.
- Set `type` to `Podcast`.
- Keep `status` current (`Not started` → `In Progress` → `Done`).
